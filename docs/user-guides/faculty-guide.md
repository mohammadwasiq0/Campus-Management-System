# Faculty Portal User Guide

## Overview
The Faculty Portal enables faculty members to manage courses, track attendance, grade assignments, and communicate with students.

## Getting Started
1. Navigate to `https://campus.example.com/login`
2. Log in with faculty credentials
3. Access personalized dashboard

## Key Features

### Dashboard
- View class schedule, pending tasks, and notifications
- Quick stats on courses and student performance

### Courses
- Manage assigned courses, upload materials
- View enrolled students

### Attendance
- Mark daily attendance with bulk operations
- Generate attendance reports

### Marks & Assignments
- Enter marks, create and grade assignments
- Track submission status

### Timetable
- View weekly class schedule
- Request schedule changes

### Research
- Submit research publications
- Track research projects

### Leave Management
- Apply for leave
- View leave balance and history

### Reports
- Generate student performance reports
- Export class-wise analytics

## Best Practices
- Mark attendance before each class
- Upload assignment materials 48 hours before deadline
- Update grades within one week of submission
