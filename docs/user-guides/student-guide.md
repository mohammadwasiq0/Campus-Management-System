# Student Portal User Guide

## Overview
The Student Portal provides access to academic records, course management, fee payments, and campus services.

## Getting Started
1. Navigate to `https://campus.example.com/login`
2. Enter your student email and password
3. Use OTP-based 2FA if enabled

## Key Features

### Dashboard
- View attendance summary, upcoming exams, fee status, and notices
- Quick access to chatbot for AI-powered assistance

### Courses
- View enrolled courses, syllabi, and faculty information
- Download course materials

### Attendance
- View subject-wise attendance records
- Attendance percentage with minimum threshold alerts

### Exams & Results
- View exam schedule and hall tickets
- Check semester results and CGPA/SGPA

### Fees
- View fee structure and payment history
- Make online payments via integrated gateway
- Generate fee receipts

### Library
- Search catalog, reserve books
- View issued books and due dates

### Hostel & Transport
- Apply for hostel accommodation
- View transport route and pass details

## AI Chatbot
- Ask questions about campus policies, schedules, and procedures
- 24/7 multi-language support
- File uploads for document processing

## Profile Management
- Update personal information, profile picture
- Manage account security and 2FA
